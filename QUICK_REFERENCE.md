## Setup Steps for Ollama

```bash
# 1. Install Ollama (one-time)
# Download from https://ollama.ai

# 2. Start Ollama server (keep running)
ollama serve

# 3. Pull the model (one-time, ~5GB download)
ollama pull qwen2.5:7b

# 4. Run the app
streamlit run risk_manager_app.py
```

That's it! Sidebar will show Ollama status.

## Troubleshooting

### "Could not connect to Ollama"
- Make sure `ollama serve` is running in a terminal
- Verify it's listening on http://localhost:11434

### "qwen2.5:7b model not found"
- Run: `ollama pull qwen2.5:7b`
- Or see SETUP_OLLAMA.md for full setup

### "cv='prefit' error"
- ✅ Already fixed in this hotfix
- Update to latest version of files

### LLM summaries still using template
- ✅ This is expected fallback behavior
- Check sidebar to confirm Ollama status
- If not running, that's why fallback is used (and that's ok!)
