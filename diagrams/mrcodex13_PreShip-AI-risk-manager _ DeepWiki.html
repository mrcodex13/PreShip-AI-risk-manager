PreShip AI Risk Manager — Overview

Relevant source files
  • FINAL_REPORT.md
  • GOALS.md
  • README.md

PreShip AI Risk Manager is a defense-only return and Return-to-Origin (RTO) risk-scoring system designed for the Indian e-commerce landscape. The system serves as a decision-support tool for merchants, prioritizing orders for manual verification based on calibrated risk signals, uncertainty quantification, and local explainability.

The project emphasizes transparency and human-in-the-loop control, strictly adhering to a non-autonomous design philosophy where the system recommends actions but never unilaterally denies service to a customer GOALS.md26-28

System Architecture and Data Flow

The application integrates a supervised learning pipeline with unsupervised novelty detection and an LLM-based explanation layer. The primary interface is a Streamlit dashboard that orchestrates these subsystems.

Key Capabilities

  1. Calibrated Risk Scoring: Unlike raw model outputs, PreShip AI uses CalibratedClassifierCV to ensure that a predicted 10% risk actually corresponds to a 10% historical return rate FINAL_REPORT.md49-50
  2. Uncertainty Quantification: The system employs Split Conformal Prediction to provide a confidence interval for every score, allowing the merchant to distinguish between "sure" risks and "borderline" cases README.md15 FINAL_REPORT.md50-51
  3. Hybrid Risk Engine: Scores are a weighted combination of a supervised Logistic Regression model (80%) and an Isolation Forest novelty detector (20%) that flags unusual numeric profiles README.md102-108
  4. Natural Language Explainability: The system transforms complex SHAP values into plain-English summaries using a local Ollama instance running qwen2.5:7b, helping non-technical staff understand risk drivers README.md17 FINAL_REPORT.md53
  5. Economic Optimization: Review thresholds are not arbitrary; they are calculated using a cost-matrix that balances the ₹ cost of a False Positive (lost sale/trust) against the ₹ cost of a False Negative (RTO logistics loss) GOALS.md17 README.md18
